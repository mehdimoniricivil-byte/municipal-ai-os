# Migration v0.4.0

پروژه فعلاً در startup از `Base.metadata.create_all()` استفاده می‌کند؛ بنابراین جداول جدید در نخستین اجرای نسخه ساخته می‌شوند.

پیش از نصب روی محیط واقعی:

1. از دیتابیس و پوشه فایل‌ها نسخه پشتیبان بگیرید.
2. نسخه را ابتدا روی محیط آزمایشی اجرا کنید.
3. وجود جداول `contracts`, `statements`, `statement_workflow`, `statement_payments`, `statement_versions` را بررسی کنید.
4. هیچ فایل یا داده واقعی تا پایان تست پذیرش وارد نکنید.

برای محیط بهره‌برداری نهایی باید این تغییرات به Migration رسمی Alembic تبدیل شوند.
