# امنیت

- `SECRET_KEY` در Production باید تصادفی، طولانی و خارج از Git باشد.
- رمز مدیر اولیه قبل از استقرار تغییر کند.
- کارشناسان فقط به واحد عملیاتی متصل به حساب خود دسترسی خواهند داشت.
- مجوزها در `app/core/permissions.py` تعریف می‌شوند.
- Audit Log قابل ویرایش یا حذف از API نیست.
- قبل از استقرار نهایی، Rate Limit ورود، Secure Cookie/Token storage، CORS محدود و HTTPS اجباری اضافه شود.
